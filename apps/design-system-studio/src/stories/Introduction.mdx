# AlMomiaa ERP Design System Studio (`@almomiaa/ui`)

Welcome to the standalone **AlMomiaa Enterprise ERP & DMS** component studio.
Every component in `@almomiaa/ui` is **pure, prop-driven, framework-agnostic**, supports **Arabic RTL (`ar-SA`) & English LTR (`en-US`)** via logical Tailwind CSS properties, and adapts automatically to **Light & Dark themes** using the canonical Gold (`#CFA434`) & Obsidian (`#1C1B1A`) token system.

## Component Inventory (27 Components)

- **Brand & Layout:** `BrandLogo`, `AppHeader`, `ResponsiveAppShell`, `Sidebar`, `SidebarNavItem`, `Tabs`, `StepProgress`, `BottomNavBar`
- **Actions & Preferences:** `Button`, `IconButton`, `LocaleSwitcher`, `ThemeToggle`
- **Forms:** `TextField`, `PasswordField`, `SelectField`, `TextareaField`
- **Data Display & Inspection:** `DataTable`, `Badge`, `SummaryCard`, `SurfaceCard`, `KeyValueList`, `EmptyState`, `PaginationBar`, `JsonResponseViewer`
- **Overlays & Feedback:** `DrawerModal`, `AlertBanner`, `NotificationItem`
