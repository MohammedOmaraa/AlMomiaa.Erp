# AlMomiaa ERP — Free HTTPS Cloud Demo Deployment Guide
# دليل النشر السحابي المجاني لتجربة النظام وتثبيت التطبيقات (بدون سيرفر مدفوع)

This runbook deploys **all 3 production-built applications** over free **HTTPS** (no credit card required for the recommended free tiers) so you and your team can test the full **Web ERP**, install the **Sales Rep Mobile PWA** on real Android/iOS phones and desktops, and run live **SignalR** notifications and **SQL Server** persistence.

---

## Architecture Overview (100% Free Demo Stack)

| App / Component | Free Host | Live HTTPS URL Example | Production Build? |
| :--- | :--- | :--- | :---: |
| **Backend `.NET 9` API + SignalR** (`apps/backend-api`) | **Render.com Free Docker** (`render.yaml`) | `https://almomiaa-erp-api.onrender.com` | Yes (`Release` Docker image) |
| **Microsoft SQL Server DB** (`45` tables, 4 EF migrations) | **MonsterASP.NET Free** / **Somee.com** / **Azure SQL Free Offer** | External SQL Server host | Yes (Canonical SQL Server) |
| **Web ERP** (`apps/web-erp`, Next.js 15) | **Vercel Free Hobby** | `https://almomiaa-erp.vercel.app` | Yes (Next.js production build + installable manifest) |
| **Sales Rep PWA** (`apps/rep-pwa`, Vite + Workbox) | **Vercel Free Hobby** | `https://almomiaa-rep.vercel.app` | Yes (Installable HTTPS PWA + same-origin cookie proxy) |

> **Why Same-Origin Proxying Matters:** Both `web-erp` (`next.config.ts`) and `rep-pwa` (`api/[...path].ts`) proxy `/api/v1/*` and `/health` through their own Vercel HTTPS domain to `BACKEND_API_ORIGIN`. This preserves `HttpOnly; Secure; SameSite=Strict` refresh cookies on **iPhone Safari, Android Chrome, and Desktop browsers** with zero third-party cookie blocking. SignalR (`/hubs/operations`) connects directly over `WSS` using the short-lived in-memory Bearer JWT.

## Step 1: Push Your Repository to GitHub
1. Create a private (or public) repository on [GitHub](https://github.com/new) (e.g., `almomiaa-erp`).
2. Push your local workspace `d:\AlMomiaa-app` to GitHub:
   ```powershell
   git init
   git add .
   git commit -m "AlMomiaa ERP ready for free HTTPS cloud demo deployment"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/almomiaa-erp.git
   git push -u origin main
   ```
   *(Double-check that `.env` and local `appsettings.Development.json` secrets are NOT committed.)*

## Step 2: Provision a Free External Microsoft SQL Server Database
Choose any one of these free SQL Server hosts:

- **Option A (Recommended — No Credit Card): [MonsterASP.NET Free](https://www.monsterasp.net/)**
  1. Register a free account -> Create a free **MS SQL Server 2022** database.
  2. Copy the **Server**, **Database**, **User Id**, and **Password** into this connection string:
     ```text
     Server=<YOUR_SQL_HOST>;Database=<YOUR_DB_NAME>;User Id=<YOUR_SQL_USER>;Password=<YOUR_SQL_PASSWORD>;Encrypt=True;TrustServerCertificate=True;
     ```
- **Option B (No Credit Card): [Somee.com Free MS SQL](https://somee.com/)** — create a free SQL database and copy its connection string in the same format above.
- **Option C (Free Forever Offer — 100,000 vCore sec/mo + 32 GB): [Azure SQL Database Free Offer](https://learn.microsoft.com/azure/azure-sql/database/free-offer)** — enable *"Allow Azure services and resources to access this server"* + firewall rule for your Render outbound IPs.

> You do **NOT** need to run SQL scripts manually! Setting `Database__AutoMigrateOnStartup=true` on Render automatically runs all 4 EF Core migrations and creates all 45 canonical tables on first startup.

## Step 3: Deploy `.NET 9` Backend API on Render.com (Free Docker)

1. Sign in to [Render.com](https://render.com/) using your GitHub account.
2. Click **New +** -> **Blueprint** (or **Web Service** -> Docker -> Root Directory: `apps/backend-api` -> Plan: **Free**).
3. If using Blueprint, Render automatically reads [`render.yaml`](../../render.yaml) and prompts you to fill in the `sync: false` environment variables:

| Environment Variable | Value to Enter |
| :--- | :--- |
| `ASPNETCORE_ENVIRONMENT` | `Production` |
| `Hosting__TrustForwardedHeaders` | `true` |
| `Swagger__Enabled` | `true` |
| `Redis__AllowInMemoryFallback` | `true` |
| `Database__AutoMigrateOnStartup` | `true` |
| `Demo__SeedEnabled` | `true` |
| `Auth__Jwt__Audience` | `almomiaa-erp-clients` |
| `Auth__Jwt__Issuer` | `https://<YOUR-RENDER-SERVICE>.onrender.com` *(update once URL is assigned)* |
| `Auth__Jwt__SigningKey` | Auto-generated by Render (or paste a random 48+ char secret) |
| `ConnectionStrings__SqlServer` | Your SQL Server connection string from Step 2 |
| `Demo__DefaultPassword` | Your chosen demo password (min 8 chars, e.g., `Demo@AlMomiaa2026`) |
| `Cors__AllowedOriginsCsv` | Temporary placeholder `https://localhost:3000` — **update in Step 6** with your two live Vercel URLs! |

4. Wait for the Docker build to finish (~3–5 minutes on first build).
5. Verify health in your browser:
   ```text
   https://<YOUR-RENDER-SERVICE>.onrender.com/health
   ```
   You should see: `{ "status": "Healthy", "environment": "Production", "timestampUtc": "..." }`.

## Step 4: Deploy `apps/web-erp` on Vercel (Free Hobby)

1. Sign in to [Vercel](https://vercel.com/) with GitHub -> **Add New... -> Project** -> import your `almomiaa-erp` repo.
2. Configure Project Settings:
   - **Project Name:** `almomiaa-erp`
   - **Root Directory:** `apps/web-erp` *(click Edit and select `apps/web-erp`)*
   - **Framework Preset:** `Next.js` *(automatically picks up `apps/web-erp/vercel.json`)*
3. Add **Environment Variables**:
   - `BACKEND_API_ORIGIN` = `https://<YOUR-RENDER-SERVICE>.onrender.com`
   - `NEXT_PUBLIC_SIGNALR_HUB_URL` = `https://<YOUR-RENDER-SERVICE>.onrender.com/hubs/operations`
   - `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` = *(optional — leave empty to use free embedded map fallback on `/gps`)*
4. Click **Deploy** and note your live URL: `https://<YOUR-WEB-ERP>.vercel.app`.

---

## Step 5: Deploy Installable `apps/rep-pwa` on Vercel (Free Hobby)

1. In Vercel, click **Add New... -> Project** -> import the **same** `almomiaa-erp` repo a second time.
2. Configure Project Settings:
   - **Project Name:** `almomiaa-rep`
   - **Root Directory:** `apps/rep-pwa` *(click Edit and select `apps/rep-pwa`)*
   - **Framework Preset:** `Vite` *(automatically picks up `apps/rep-pwa/vercel.json` and `api/[...path].ts`)*
3. Add **Environment Variables**:
   - `BACKEND_API_ORIGIN` = `https://<YOUR-RENDER-SERVICE>.onrender.com`
   - `VITE_SIGNALR_HUB_URL` = `https://<YOUR-RENDER-SERVICE>.onrender.com/hubs/operations`
4. Click **Deploy** and note your live URL: `https://<YOUR-REP-PWA>.vercel.app`.

---

## Step 6: Link Both Vercel HTTPS Origins in Render CORS (Critical!)

1. Go back to **Render Dashboard** -> your `almomiaa-erp-api` service -> **Environment**.
2. Set `Cors__AllowedOriginsCsv` (exact origins, **no trailing slashes**, separated by a comma):
   ```text
   https://<YOUR-WEB-ERP>.vercel.app,https://<YOUR-REP-PWA>.vercel.app
   ```
3. Confirm `Auth__Jwt__Issuer` equals `https://<YOUR-RENDER-SERVICE>.onrender.com`.
4. Save changes (Render will automatically restart cleanly in ~30 seconds).

## Step 7: Install the Mobile PWA & Web ERP on Real Devices (تثبيت التطبيق)

### Android (Chrome / Edge)
1. Open `https://<YOUR-REP-PWA>.vercel.app` in Chrome.
2. Tap the in-app **تثبيت التطبيق / Install App** banner (or Chrome menu `⋮` -> **Install app / إضافة إلى الشاشة الرئيسية**).
3. **AlMomiaa Rep** appears on your home screen as a full-screen standalone app!

### iPhone / iPad (Safari)
1. Open `https://<YOUR-REP-PWA>.vercel.app` in **Safari**.
2. Tap the **Share** icon (`⬆️`) -> **Add to Home Screen / إضافة إلى الشاشة الرئيسية** -> **Add**.

### Desktop (Windows / macOS Chrome or Edge)
- Open either `https://<YOUR-WEB-ERP>.vercel.app` or `https://<YOUR-REP-PWA>.vercel.app` and click the **Install icon** (`⊕`) in the address bar!

## Operational Notes for Free Tier Demo

- **Render Free Cold Start:** Render spins down free Docker services after 15 minutes of inactivity. The first request after idle takes ~30–50 seconds to wake up.
- **Optional Zero-Cost Keep-Alive:** Create a free monitor on [UptimeRobot](https://uptimerobot.com/) or [cron-job.org](https://cron-job.org/) hitting `GET https://<YOUR-RENDER-SERVICE>.onrender.com/health` every **14 minutes** to keep the demo warm during testing hours.
- **Switching to Real Production Later:** Set `Demo__SeedEnabled=false`, `Database__AutoMigrateOnStartup=false`, `Redis__AllowInMemoryFallback=false`, provide a managed Redis URL in `Redis__ConnectionString`, and upgrade to a paid always-on container + production SQL Server instance.
